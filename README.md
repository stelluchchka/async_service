## Описание проекта

Асинхронный сервис оплаты реализован на языке Go и предназначен для обработки платежей и обновления статуса заказов в системе заказов блюд быстрого питания. Сервис взаимодействует с основным веб-сервисом через REST API и обеспечивает асинхронную обработку запросов на оплату.

## Основные функции

- **Обработка платежей**: Сервис проверяет успешность оплаты заказа и обновляет его статус.
- **Асинхронная обработка**: Сервис работает асинхронно, что позволяет обрабатывать запросы на оплату без блокировки основного потока выполнения.

## Технологии

- **Язык программирования**: Go (Golang)
- **Фреймворк**: Стандартная библиотека Go
- **База данных**: PostgreSQL (через основной веб-сервис)

## Установка и запуск

### Предварительные требования

- Убедитесь, что у вас установлен [Go](https://golang.org/) версии 1.16 и выше.

### Шаги для запуска

1. **Клонируйте репозиторий:**

```bash
git clone https://github.com/stelluchchka/payment_service.git
cd payment_service
```
2. **Запустите сервис:**
```bash
go run main.go
```
3. **Сервис будет доступен по адресу:**
http://localhost:8080

## API

### Обработка платежей

- POST /calc/: Обработать ответ от платежного сервиса.

Входные данные:
```json
{
  "order_id": 123,
  "token": "payment_token",
  "is_success": true
}
```
Выходные данные:
```json
{
  "id": 123,
  "status": "approved",
  "created_at": "2023-10-02T12:00:00Z",
  "processed_at": "2023-10-02T12:05:00Z",
  "completed_at": "2023-10-02T12:10:00Z",
  "user_id": 456,
  "moderator_id": 789,
  "is_success": true
}
```
